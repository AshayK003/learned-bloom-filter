# Security Policy

## Safety Notice

This project processes URL data for benchmarking. All data is treated as **text only**. No URLs are opened, downloaded, or executed.

- **No network calls at runtime** (only during data download from URLhaus).
- **No code execution** from URL strings.
- **All data is local** — never transmitted to third parties.

## Reporting Vulnerabilities

Open a GitHub Issue if you find a security concern.
